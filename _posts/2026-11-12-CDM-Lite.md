   About a year ago, I had a chance to see the work that FINOS is doing, particularly around the Common Domain Model (CDM),
   but I didn't want to install Java to explore it.

   CDM is an open-source standard for representing financial products and trades including their lifecycle events.  It's a substantial
   project, and while Python support is intended to be available, I found that it wasn't quite working as expected when I
   tried it.

   That got me wondering whether there was a simpler way.

   The CDM project publishes JSON schemas, and there's an excellent open-source Python project called *datamodel-code-generator*, maintained
   by my friend Koudai Aono, which can generate Pydantic models from JSON schemas.

   So I put the two together.

   The result is **cdm-lite**, a small Python CLI tool that provides a lightweight way to explore CDM using Python, without the need for
   the full Java tooling.

   To be clear, datamodel-code-generator does much of the heavy lifting here. My contribution is largely about bringing the pieces
   together, and making it as easy as possible to use.

   It's also been a useful opportunity to learn more about the practical side of publishing an open-source Python package: packaging,
   testing, CI/CD, versioning and publishing to PyPI.

   The project hasn't attracted much attention so far, but I've learned a lot from building it. Maybe the most enjoyable part has
   been being able to build something useful (I hope) on top of the work of other developers.

   If you're working with CDM, Python or financial data standards, I'd be interested to hear what you think.

   You can find the project on [PyPI](https://pypi.org/project/cdm-lite/).
